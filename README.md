Лабораторна робота № 5 з дисципліни «Основи інженерії програмного забезпечення».

Програма рахує значення виразу

- y = П(j + 1), j = 2..n-2, якщо x < 0
- y = Σ(i = 0..n-1) П(j = 0..n-1) (x + i + j²), якщо x ≥ 0

на проміжку [a, b] з кроком h.

- `calc.h`, `calc.cpp` - функції обчислення і перевірки даних
- `main.cpp` - консольна програма
- `unittest1.cpp` - модульні тести (Native Unit Test Project, Visual Studio)
